### 20:52:02 *仮想デスクトップ*

Windows 仮想デスクトップをもっと活用しようという気持ちになった.
使ってる, またはすぐ使う可能性のあるウィンドウはどこかのデスクトップで必ず開いておく.
１回起動したらほぼ用事のないウィンドウは, 最小化させておく.

本来の Windows ショートカットキーもあったりするが,
`Win+Alt+?`
でまとめようとしてる.
統一感がないと指が混乱するので.

一個のデスクトップでは,
そのデスクトップで作業するウィンドウだけがタイリングで敷き詰められている.
どれかのウィンドウがどれかによって隠れているという状態を作らない.
一瞬専念するときは（例えばブラウザ）その時だけそれを最大化し, 用が済んだらすぐに元のサイズに戻す.

```
; AHK v2

; 仮想デスクトップ切り替え
##!h::Send("^#{Left}")          ; 仮想デスクトップ左へ
##!l::Send("^#{Right}")         ; 仮想デスクトップ右へ

; ウィンドウの最大化/元のサイズに戻す
##!j::WinRestore("A")   ; restore
##!k::WinMaximize("A")  ; maximize

; ウィンドウ切り替え（実験中！）
##!n::Send("!{Esc}")
##!p::Send("!+{Esc}")
```

最後のウィンドウ切り替えは定番なのは `Alt+Tab` と `Win+Tab` だが,
`Alt+Esc` は切り替え先を確認するミニウィンドウが出ることもなく確認なしに切り替える.
また最小化してるウィンドウが切り替え対象に **ならない**.
なので最初に言った「使わないウィンドウは最小化しておく」という方針と相性が良い.

ただし一個罠があって,
「どのウィンドウにもフォーカスしてない状態」も遷移先の一つとして扱われる.
あ, あと, 今どれにフォーカスが当たってるか分かりにくい問題がある.

なのでそこは AHK でリッチに実装しようとしてる, 今.

どうやら最小化されててもフォーカスを送ってるらしい?
ただし最小化されたままで.

- `!{Esc}` を送る
    - 最小化されてるならまた `!{Esc}` を送る
    - ウィンドウタイトルが空文字列ならまた `!{Esc}` を送る
        - (どこにもフォーカスされてない状態に相当?)
- ウィンドウのタイトルをデスクトップのド真ん中に大きく表示する
    - どこにフォーカスしたか分かる

### 18:25:07 *SteamFrameでやったこと*

#### キーボードの設定

英字キーボードを追加して, 仮想キーボードを英字キーボードで用意しておく. これでないと入力できない場面がある.

SteamVR の設定 (Bluetooth > デバイス追加) で Bluetooth キーボードも接続できるので, 接続しておく. 仮想キーボードには Ctrl や Esc キーがない！

#### 開発者モードの有効化

Frame Setting > System から開発者モードを有効にする. すると Developer (開発者設定) というタブが新しく出てくるので, そこで「User Password」を設定できる. このパスワードは SSH 接続するときと, sudo コマンドを実行するときに使う.

#### SSH 接続

さっき設定した User Password で, 他の PC から Steam Frame に SSH 接続できる. username は steamos, hostname は frame (Windows からならホスト名が解決できる. 別の端末から接続する場合は適当に IP を調べる).

```bash
ssh steamos@frame
```

#### readonly をやめる

デフォルトではシステム部分のファイルが readonly になっていて, システムにコマンドをインストールできない (pacman -S で「データベースをロックできない」というようなエラーが出る). 次のコマンドでこの安全機構を無効化できる.

```bash
sudo steamos-readonly disable
```

### 18:29:00 *HSK5 勉強法*

#### 前提
HSK3 は1年前に取得済みで, 最低限の文法と簡単な単語はわかる状態からスタート.
5級になって語彙はもちろん増えるが, それよりも接続詞の種類が増えるのが厄介だった.
とにかくリアルな文章を多く読んでいって, 実際に使われる接続詞をひたすら覚えるしかない.

#### 試験1ヶ月前まで
試験のことは意識せず, 何でも読んだ. 本を読み込むのが主で, 音声が提供されている本を選んで読んだ. 面白かったのは朝日出版社の時事中国語の教科書の2026年版.
タイトル通り時事ニュースを扱うもので私には面白かった.
当たり前過ぎることを言うけど, 興味の持てるコンテンツを見つけられさえすれば語学は勝ち.

#### 試験後に始めたもの
試験の後に, 月刊誌「聴く中国語」を書店で見つけて読み始めた.
内容はだいたい時事ニュースか, 中国のどこかの場所や歴史を紹介するコラム, それに詩の紹介. タイトルの通り, 基本的に全部に音声がついていて, 目次にまで音声がある. MP3 はインターネットから自由にダウンロードして使える. 変なアプリに頼らなくて済むのが一番いい. 試験の後に始めたので HSK5 には直接効かなかったが, 普段の勉強としてはめっちゃおすすめ.

#### 試験1ヶ月前から
このままだとダラダラと緩い勉強だけを続けるだけで, 目標にしていた HSK5 をいつまでも受けないなと思ったので自分を追い込む目的で試験に申し込んだ.
ちょうど一ヶ月後の試験があったので申し込んだ.
結果的には「試験一ヶ月前から試験勉強を始めた」ということになるが,
正確には「試験を一ヶ月後に設定したので強制的に慌てて勉強を始めた」というのが正しい.

HSK 公式アプリの買い切りの「HSK単語トレーニング」で, 4級と5級をひたすらやった. ランダムに出る単語をリスニングして, わからなければ後で意味と例文を確認できる機能が良くて, 暇なときにやっていた.
過去問は2021年度版を買い, 音声付きアプリで5年分を週1, 2セットのペースで解いた. 土日に過去問を通しで解き, 平日は満点が取れるまで何度も繰り返し解き直した.
私はこれであらゆる受験を乗り切ってきたんだ.
ほかに毎日 Duolingo もやっていたが, 簡単すぎるので, 中国語を勉強する気持ちを作るための装置.

#### 听力 (Listening)

ここでは, とりあえず受かることを目的に設定している.
「**本当の意味で** 中国語を理解し, 中国人と対等に会話し, 中国語の映画を字幕なしで理解する」などと大それた目標は捨て去ることだ.
受験料の 9900 円は安くない.

というわけで, 听力 の解き方はズバリこうだ.

- 聞こえてきたキーワードを含む選択肢を選ぶ
- 選択肢が非道徳的なものなら消す

これだけですね.
これで確率 50% は確保できる.
正答には二種類しかなく,
キーワードそのままを答えたら良い素直パターンと,
キーワードの真反対である裏切りパターンの二つである.
二つに一つが正解なので 50% だという計算だ.
決してふざけて言って無くて, 過去問で実験したら本当にこれで 50% 超えた.
なので後はどれがキーワードっぽいかを聞き取るゲームになる.

あと, 続く Reading でもそうだが,
登場人物は全て善人なので, 回答が非道徳的なものはありえないと思って大丈夫.

#### 阅读 (Reading)

これは日本人なんで読めるよね?
名詞は全部読み取れましょう.
副詞も八割くらいはニュアンスが取れて当然.
敢えて言えば人名が取れないことがあるくらい.
どこからどこまでが人名でどこが敬称なのか.

接続詞は急に増えるので頑張る.
分からなかったら無視して読むのも一つの手.

#### 写书 (Writing)

10問で40分. 1から8問目は語順の並べ替え, 9問目は指定された5つの単語を使って80字くらいの短文, 10問目は絵を見て80字くらいの文章を書く.
並べ替えは出来上がる文の意味を予想しながら組み立てるのが意外と難しい.

自由作文は, とにかくどうでもいいミス, 例えば難しい接続詞使ったり単語使って間違えるようなみっともないことをせず,
プライドを最大限捨て, 小学生レベルの作文に徹する.
これだけですね.

とはいえ, 過去問やってても, 採点基準が明かされてるわけではないので, どこまでが正解なのかはわからない.
過去問をやってたときは AI に丸投げして採点させ,
かつミスを指摘させ満点がもらえるまでブラッシュアップするという練習を積んだ.

これは完全に想像というか妄想だが,
100点中50点が並び替え, 50点が自由作文だと思って自己採点してた.

#### 過去問との一致
HSK3 のときはリスニングで過去問が全くそのまま出たものであるが,
HSK5 ではリーディングの最初の2問が選択肢とその順序まで含めて, 過去問と完全に一致していた.
出題側も回答側も時短ですね.

#### 考えてた目標

- Listening: 60/100
    - 前に言ってた50% は確保できる理論と, あとは努力と運でこのくらい
- Reading: 90/100
