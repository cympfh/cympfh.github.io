16:12:15 gogyo キーボードレイアウト

去年の12月から試してる試み. 完全に自分でキーボードレイアウトを考えてみようの続き. レイアウト自体は去年の12月からほとんどは変わってない.

キー配置は次の通り. ただしこれは日本語入力のときだけで, 英語入力はただの QWERTY 配列.

Ya Yi Yu Ye Yo G  Z  D  B  P
 A  I  U  E  O  K  S  T  N  H
   _  X  _  V  R  ん W

ここで _ は使ってないの意味.

特徴

  • 左手に母音を「あいうえお」で並べる
    • 「やゆよ」も母音だろの気持ち
  • 右手に子音を「かさたなは」で並べる
    • 濁音「がぎぐげご」はすぐ上に置く
  • 拗音は子音+「やゆよ」
    • K Ya で「きゃ」, S Yu で「しゅ」

前回からの変更点

  • 名前を gogyo にした
    • GODAN キーボードを横に倒した形なので五段→五行
  • ローマ字を一部破壊してる
    • T N を M の代用として使う
      • 例えば
        • T N A で「ま」
        • T N Yu で「みゅ」
      • 理由は N に近くしたいのと, 打ちやすさから
    • 「しょう」は S Yo Yo で打つ
      • 「しょう」って「しょ」+「う」ってよりは「しょ」+「お」じゃん
      • でも Yo から O は同じ指で縦動かすのが難しいから Yo 2回で「ょう」相当にした
    • 「しゅう」は S Yu Yu で打つ
      • 全く同様
    • 「しゃあ」は S Ya Ya で打つ
      • 全く同様
    • 「ふぁふぃふゅふぇふぉ」は F Ya ~ F Yo で打つ
    • 小文字は X の次に母音を打つ
      • 例えば
        • X A で「ぁ」
        • X Ya で「ゃ」

  構成手順 (x を起点に7ステップ):
  s  = EML(x, 1)      # = exp(x)
  t  = EML(x, s)      # = exp(x) - log(exp(x)) = exp(x) - x > 0

  ee = EML(s, 1)      # = exp(exp(x))
  -x = EML(w, ee)     # = exp(log(t)) - log(exp(exp(x))) = t - exp(x) = -x

19:01:59 日本語にも声調はある

中国語の勉強始めて意識したこと. 何人かの中国人たちに日本語に声調があるのかと聞かれて, もちろんそんなものは無いと答えてきたがあれは嘘だった.

学習者にとっての重要性だとか, 二の次具合はあるけど, 無いわけじゃ無いよというのは言うべきだと反省した.
